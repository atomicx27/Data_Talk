## 1. Deep Audit of Current Implementation (Observed Gaps & Bugs)

Our audit of the existing 1,174-line [`RootCauseAgent`](file:///c:/Users/pashi/Desktop/Data_Talk/src/agents/root_cause_agent.py#L28) and its orchestration/UI layers identified **four critical integration failures** and **five analytical/engineering limitations**:

### 1.1 Critical Integration & UI Defects Found
1. **LangGraph Supervisor Crash (`supervisor_graph.py#L75`)**:
   - `run_root_cause()` builds `avail_metrics = [m["id"] ...]` even though `RootCauseAgent._extract_metrics()` keys every metric dictionary by `"column"` (not `"id"`). Every Supervisor-routed `"Why did ..."` call raises `KeyError: 'id'`, caught into an error fallback (`tests/test_langgraph_engine.py#L753-L754` never asserted `success is True`).

   - `kpiRibbonHtml` renders `"N/A"` in 3 of 4 cards for `auto_scan`; `formatMarkdownBold` leaks raw `$\sum \Delta = ...$` LaTeX strings (`root_cause_agent.py#L292`).
4. **Silent Test Blind Spots (`tests/test_root_cause_engine.py`)**:
   - `cohort` fallback compares `t0_predicate="1=1"` vs `t1_predicate="1=1"` (all deltas = `0.0`), while `test_non_temporal_cohort_fallback` only checks `not res["df"].empty`.

### 1.2 Analytical, SQL & Security Limitations
5. **1D-Only Scanning (Misses Multi-Dimensional Root Causes)**: `_decompose_additive`, `_decompose_rate_mix`, and `_auto_scan_dimensions` inspect **1 dimension at a time** (and stop after `dimensions[:8]`). Localized 2-way anomalies (e.g., `EMEA × Edge Hardware`) are diluted inside 1D marginals.
6. **Temporal & Seasonality Blindness**: Fixed 91-day windows mix pre/post-inflection regimes, misalign calendar YoY (`SUBSTR(..., 1, 4)` compares partial year-to-date against full prior year), fail silently on integer year/month columns (`date.fromisoformat` reverts to `date.today()`), and use string `BETWEEN` on timestamps. Joined date tables fail at execution because `window_spec["join_lineage"]` is never joined into decomposition queries.
7. **Statistical Noise & Metric Bias**:
   - `_auto_scan_dimensions` lacks minimum-support thresholds, confidence intervals, and multiple-testing control (small segments cause false positives); divides `excess_score` by `2 * abs(fleet_delta)` (saturating at `1.0` whenever segments offset); and filters `WHERE (v0 > 0 OR v1 > 0)`, silently dropping negative/loss metrics.
   - `0 -> +X` shows `0.0%` growth; negative baselines invert growth sign; `rate_mix` divides by rounded 2-decimal SQL buckets and attributes 50/50 mix/rate when `total_d0 == 0`.
   - `_apply_pareto_rollup` leaves `NaN` in `rate_effect`/`mix_effect` for the `"All Other"` row on `rate_mix` scatter plots.
8. **Cross-Dialect, Semantic Measure & PVM Gaps**:
   - `ROUND(double_precision, 2)` fails on PostgreSQL; `CAST(... AS VARCHAR)` fails on MySQL; `DATE '...'` and `SUBSTR` fail on SQLite/T-SQL; table/column identifiers are unquoted; selecting any `SemanticMeasure` crashes; only a single primary fact table is considered; no 3-factor Price × Volume × Mix decomposition exists.
9. **Privacy Firewall Bypass on Direct Calls**: `connector.execute_query(...)` in `root_cause_agent.py` does not pass `blocked_tables` / `blocked_columns` and never validates custom date strings / identifier inputs; `_discover_conformed_dimensions` checks a 6-word list instead of `col.is_pii` / `PrivacyFirewall.is_pii_column_name`.

### 2.2 Temporal Regime Alignment & Change-Point Detection
* **Why Fixed 90-vs-90 Windows Fail:** Fixed windows mix incompatible regimes across an inflection date, skew weekday/weekend ratios when not multiples of 7 days, and fail when `yoy` isn't YTD-aligned. (Note: **Prophet** defaults to `changepoint_range=0.8`, making it blind to shifts in the most recent 20% of history!)
* **Recommended Pipeline (Decompose First, Then Detect Inflection):**
  1. Strip day-of-week ($p=7$) and annual seasonality cleanly via **STL** (Cleveland et al. 1990) or **MSTL** (Bandara, Hyndman & Bergmeir 2021) using robust bisquare weights.
  2. Detect optimal break date(s) via **PELT** (Killick et al. 2012; Truong et al. 2020 `ruptures`, penalized via modified BIC / mBIC to prevent autocorrelation over-segmentation) or **CUSUM** (Page 1954; Meta Kats) / **E-Divisive with Medians** (James et al. 2014 `BreakoutDetection`) for heavy-tailed metrics, keeping **BOCPD** (Adams & MacKay 2007; Knoblauch et al. 2018) optional for online uncertainty scores.

### 2.4 Deep Multi-Step Agentic LangGraph RCA Loop
* Rather than unbounded ReAct loops (documented failure mode in ServiceNow **InsightBench**), structure historical BI diagnostics as a deterministic-seeded **Plan-and-Execute LangGraph `StateGraph`**:
  1. Deterministic pre-step (`regime_and_scan`: changepoint check + BH-FDR multi-dim scan + PVM/Das Gupta);
  2. `hypothesis_planner` fanning out via **`Send(...)`** isolated subgraphs with state quarantine returning compact Pydantic `EvidenceRecord`s;
  3. **`counterfactual_ablation` node** (computing exact leave-one-out segment neutralization $\Delta \text{KPI}_{\setminus S}$);
  4. `critic_evaluator` checking cumulative explained variance ($\ge 70\%$) and bounded depth;
  5. `citation_audited_synthesizer` verifying every cited figure against computed `EvidenceRecord`s.
